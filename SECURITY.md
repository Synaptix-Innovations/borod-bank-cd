# Security policy

`borod-bank-cd` is part of Borod Bank, the reference project of [Synaptix Innovations](https://github.com/Synaptix-Innovations). It is a demonstration platform, not a production banking service, and holds no real customer data.

## Reporting a vulnerability

Please report privately, not in a public issue or pull request:

- Use [GitHub private vulnerability reporting](https://github.com/Synaptix-Innovations/borod-bank-cd/security/advisories/new) for this repository, or
- write to info@synaptixtech.net.

Include what you found, where, and how to reproduce it. We acknowledge a report within 5 business days and tell you what we plan to do about it. Please give us reasonable time to fix an issue before disclosing it.

## Supported versions

Only the `main` branch is maintained.

## Scope

In scope: the code and configuration in this repository. Out of scope: findings that need physical access, social engineering, denial-of-service testing against our infrastructure, and third-party services we only consume.
